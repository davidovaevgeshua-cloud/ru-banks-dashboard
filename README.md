# iMOEX banks dashboard

Интерактивный дашборд сравнения публичных банков РФ: Сбер, ВТБ, Т-Технологии, ДОМ.РФ, Совкомбанк, БСПБ, МТС Банк.

Живой URL: см. вкладку **Actions → Deploy to GitHub Pages** после первого запуска.

## Что внутри

- `index.html` — статичная страница с интерактивными графиками (Plotly), карточками KPI и таблицей форвардных мультипликаторов на 2026–2028.
- `data/payload.json` — все ряды: цена закрытия, LTM/NTM-мультипликаторы, ROE, NIM, CIR, CoR, NPL, достаточность капитала (Н20.0), прибыль/капитал/активы, дивиденды, прогнозные NI/EQ/DPS.
- `data/status.json` — метаданные последнего обновления котировок.
- `data/quotes.json` — компактный лог последних 30 дней котировок каждого банка.
- `scripts/update_quotes.py` — тянет MOEX ISS и пересчитывает мультипликаторы.
- `.github/workflows/update-quotes.yml` — расписание обновлений.
- `.github/workflows/pages.yml` — деплой на GitHub Pages.

## Расписание автообновления

Пять запусков в рабочие дни (МСК):

| Время МСК | Что происходит |
|---|---|
| 12:00 | Утренний срез |
| 15:00 | Дневной срез |
| 17:00 | Дневной срез |
| 19:00 | Дневной срез |
| 23:59 | Финальный прогон, точка становится ценой закрытия (`--finalize`) |

Внутри дня новая точка `close` перезаписывается на каждом запуске; последний прогон дня фиксирует цену закрытия.

Тикеры MOEX: `SBER`, `VTBR`, `T`, `DOMRF`, `SVCB`, `BSPB` (+ `BSPBP` для расчёта mcap с префами), `MBNK`, индекс `IMOEX`.

## Ручной запуск

- Actions → **Update MOEX quotes** → Run workflow. Опция `finalize=true` эквивалентна `--finalize`.
- Локально: `python3 scripts/update_quotes.py [--finalize] [--dry-run]`.

## Что пересчитывается при обновлении цены

- `close` (ряд + last)
- `mcap` (`shares × close`, сохранённое shares outstanding берётся из `_shares`)
- `pe_ltm`, `pb_ltm`, `ptbv_ltm` — от новой mcap и последних отчётных NI/Equity
- `pe_ntm`, `pb_ntm`, `ey_ntm` — пропорционально изменению LTM
- `tr_index`, `dd_tr` — приближённое обновление от изменения цены
- Таблица форвардных мультипликаторов (`table.rows`): `pe`, `pb` по каждому году, `dy` для непроплаченных лет
- Карточки `last`: `close`, `mcap`, PE/PB LTM+NTM, изменение %, 3M/1Y return (цена и TR)
- `updated` — метка обновления МСК

Полные фундаментальные ряды (ROE, NIM, CIR, CoR, NPL, достаточность капитала, прибыль/капитал/активы) — обновляются вручную из отчётности банков.
